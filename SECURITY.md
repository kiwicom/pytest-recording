# Security Policy

## Supported Versions

Only the latest release gets security fixes.

## Reporting a Vulnerability

[Open a private security advisory](https://github.com/kiwicom/pytest-recording/security/advisories/new)
or email dmitry@dygalo.dev. Do not open a public issue.

Include:

- the affected version
- steps to reproduce or a proof of concept
- a suggested fix, if you have one

Expect a first reply within a few days.

## Disclosure

Security fixes ship in regular patch releases, and the [changelog](docs/changelog.rst) lists them.
After the fix is released, you may publish your findings.
I publish a GitHub security advisory and request a CVE when the issue warrants one.
